# Assignment 2-3 Part B – IDE Features Reflection







Overall, I enjoyed using Visual Studio Code for this assignment. I had used
it in the past, but this project gave me more practice using it with Python.
The three features I found most useful were the integrated terminal, GitHub
Copilot, and Python Environments. These features helped me write, run, test,
and review my program in one place. They can support beginning programmers by
making errors easier to find and giving them an organized workflow.

## Feature 1 – Integrated Terminal

The integrated terminal lets me run commands without leaving Visual Studio
Code. I used it to run `name_age.py`, enter test values, and run the provided
acceptance tests after making changes. When I needed to check the program
again, I could rerun the same command and quickly see whether the output was
correct. This made testing more efficient because I did not need to switch to
another application or remember a separate workflow.

## Feature 2 – GitHub Copilot

GitHub Copilot helped me identify when I was moving in the wrong direction and
review whether my work matched the assignment rubric. For example, it pointed
out that adding a `Message` class was unnecessary for this small program and
that the provided `main()` function and main guard should be preserved. It
also helped me compare the program with the rubric while I refined it. This
was useful because beginning programmers can receive guidance about simpler
solutions while still checking and understanding the code themselves.

## Feature 3 – Python Environments

Python Environments helped me create and use a virtual environment for the
project. I used the `.venv` environment to run both the program and the
acceptance tests with the project’s Python interpreter. This kept the project
setup separate from the rest of my computer and gave me practice with a
workflow that is useful for larger Python projects. The environment tools also
made it easier to confirm which interpreter was running my code.

## Conclusion

Using Visual Studio Code with Python was a good test of my ability to work
through a new language while using an IDE. The integrated terminal helped me
run and test the program, Python Environments helped me manage the project
interpreter, and GitHub Copilot helped me refine the code against the rubric.
These features will help me organize future projects and find problems more
efficiently.
