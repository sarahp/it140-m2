IT 140 Module Two Assignment Guidelines and Rubric

Overview

An integrated development environment (IDE) is a tool for programmers to write, run, test, and organize their code. Some IDEs are designed for a specific programming language, such as PyCharm for Python, while others, such as Visual Studio Code (VS Code), can be used in many different programming languages.

In this assignment, you will write and run a simple Python program in your IDE. This program will prompt the user to manually input the requested information from their keyboard, perform a calculation on the input data, and output a formatted message to the display for the user to read.

Prompt

For this project, you will be developing a Python (.py) file that contains your code using your IDE and evaluating a few of its features. If you haven’t already, complete the Module One Setup Tasks before continuing with this assignment.

Part A

In your IDE, write a program that prompts the user for their name and age. Your program should then tell the user the year they were born. Assume the user has already had their birthday this year. You do not need to ask for the user’s date of birth.

The following sample runs were run in 2025. Do not type 2025 directly into your code as a fixed value. This is called hardcoding, which means putting one specific value into your script even though that value may change later. Instead, your script should use the real-world current year at the time you are writing and testing your code.

Here are two sample executions of the program with the user input in bold:

Sample Run 1

What is your name? Alex
How old are you? 24

Hello Alex! You were born in 2001.

Sample Run 2

What is your name? Jordan
How old are you? 37

Hello Jordan! You were born in 1988.
  1. In your IDE, write a program that prompts the user for their name and age. Your program should then tell the user the year they were born. Assume the user has already had their birthday this year. You do not need to ask for the user’s date of birth. Format your code using best practices. Refer to the zyBooks style guide, if needed, to use proper naming conventions for variables and methods. Use the most appropriate statements with minimal extraneous elements, steps, or procedures.
  2. Run the program.
  3. Debug the program. Be sure your code produces the correct results.
  4. Save and submit your file.

Part B

While you don’t need an IDE to write a program, there are some features that make it desirable. What did you notice when using your IDE to develop a simple program? For instance, you might have noticed how color is used. Identify two to three features that could make coding easier for programmers and briefly explain why.
